# Automate Polygon Blockchain Workflows with Our New n8n Community Node

We're excited to announce the release of n8n-nodes-polygon, a powerful community node that brings Polygon blockchain automation to n8n workflows!

## The Challenge: Bridging Web3 and Automation

As blockchain technology continues to evolve, developers and businesses need efficient ways to interact with Polygon networks. Whether you're monitoring wallet transactions, tracking NFT collections, analyzing token movements, or managing smart contract interactions, doing this manually or through custom scripts is time-consuming and error-prone.

That's why Velocity BPA created n8n-nodes-polygon—to make blockchain automation accessible to everyone, from developers to business analysts.

## What Can You Do With This Node?

Our Polygon node supports both Polygon PoS and zkEVM networks, giving you comprehensive access to:

- **Account Operations**: Query wallet balances, transaction histories, and account details
- **Transaction Monitoring**: Track and analyze transactions across the network
- **Token Management**: Work with ERC-20 tokens, check balances, and monitor transfers
- **NFT Operations**: Query NFT collections, ownership data, and metadata
- **Smart Contract Interactions**: Read from and interact with deployed smart contracts

## Real-World Use Cases

Imagine automatically sending Slack notifications when a specific wallet receives a payment, triggering workflows based on NFT transfers, syncing blockchain data to your CRM, or generating daily reports on token holdings—all without writing a single line of code.

## Getting Started

Installation is straightforward. In your n8n instance, run:


npm install n8n-nodes-polygon


Restart n8n, and you'll find the Polygon node in your node palette, ready to integrate into your workflows.
